# 表单易用性盘点与修补：本地验收记录

日期：2026-09-24。任务来源：`OPERATIONS-USABILITY-PLAN.md` 恢复施工第二项——盘点可见表单中要求手填内部编号、不规范金额输入和缺确认的高风险操作，并沿用现有模块最小修补。仅本地实现与验证，未提交、未推送、未部署、未写友方云业务数据，未修改小程序前端与个人线。

## 盘点结论（只读核查，三张清单）

- **内部编号**：可达表单无"必须手填 ID 才能提交"的硬伤，名称选择器均在打开时注入；残留为隐藏模板内部编号味文案、退款表显示裸订单 ID、审计页显示内部定位（审计页属超管诊断，保留合理）。
- **金额**：无可达的"直接填分"输入，展示侧全部带 ¥ 并按元换算；残留为运费表格只显示基础运费、商品工作流页价格无保存前换算预览。
- **确认缺口**（按风险降序）：①"专业资料"编辑在售商品无确认；②SKU 表单状态下拉可绕过行内按钮确认直接上下架；③分类/轮播/首页模块/仓库保存即启用无确认；④商品工作流页在售商品改价无确认；⑤素材登记/新建版本无确认；⑥商品媒体关联启用无确认。无批量自动决定入口（批量上架/批量启用等不存在）。
