# FR-RECEIPT-01A：企业下单到受控收款接口

规格：FR-RECEIPT-01-规格草案.md v1，用户已确认步骤及本地验收。
唯一当前步骤，状态索引为 OPERATIONS-USABILITY-PLAN.md；主 Agent 串行负责友方 API 与直接测试，禁止修改小程序和个人线。

交付：企业线下下单为待收款，权限允许后按实际金额登记，部分/收齐准确，重复请求不重复计入，履约状态独立；历史不明账目拒绝推定为零。

执行顺序：边界失败测试→修复现有模块→实际 dispatch 鉴权/同单测试→相关全测→独立审查。不得重写已有购物与定价逻辑。
最低用例：历史缺实收字段、非法日期、金额、权限、幂等冲突、超收、事务失败回滚、取消订单、发货/送达分离；从实际下单进入收款链路。
完成条件：上述测试与审查通过才交接01B；内存验证不代表云事务通过。01B订单界面和01C同单演示沿用已确认顺序，到对应步骤再细化。
回退：收款模块/路由/权限/新订单字段/取消保护作为一组定向撤回，保留其他未提交整改；禁止提交推送部署及云端写入。
