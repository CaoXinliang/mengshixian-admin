# CloudBase 安全规则部署清单

本项目的业务数据全部通过 `api` 云函数读写。不要为了让网页后台工作而把数据库或云存储设置为“所有用户可读写”。以下规则需要由环境管理员在 CloudBase 控制台确认后配置；本文件是模板，不会自动改动任何云环境。

## 数据库

对于所有业务集合，客户端直接读写应禁止：

```json
{
  "read": false,
  "write": false
}
```

云函数服务端 SDK 不受客户端安全规则限制，仍可按本项目的角色和用户校验读写数据。

## 云存储

建议将已审核、允许商品端访问的图片放在 `public/` 前缀。所有客户端写入禁用：

```json
{
  "read": "/^public\\//.test(resource.path) == true",
  "write": false
}
```

管理员上传原始文件时使用 CloudBase 控制台或受控运维流程，并在后台登记文件 ID。不要给匿名网页登录开放写权限；当前后台不会调用浏览器直传接口。

## 云函数

`api` 需要允许小程序、网页商城和管理后台调用，函数自身再按 action 执行用户或管理员权限校验；`maintenance` 只能由 CloudBase 定时触发器调用，必须拒绝所有客户端调用。环境级函数安全规则应为：

```json
{
  "*": { "invoke": false },
  "api": { "invoke": true },
  "maintenance": { "invoke": false }
}
```

以上 JSON 同时保存在 `function-security-rules.json`，用于控制台粘贴与审查。发布前检查：

1. 未登录调用只能访问 `health`、`catalog.*`、`content.*`；
2. 用户购物车、地址和订单需要 CloudBase 微信身份；
3. 后台写操作必须携带服务器创建的管理员会话；
4. 禁止给任何客户端管理数据库或存储的直接权限；
5. 配置管理后台实际域名为 CloudBase Web 安全域名，测试域与正式域分开。
6. `maintenance` 每 5 分钟运行一次，检查库存预占和失败/过期拼团；定时触发器不应携带管理员令牌。

CloudBase 的客户端安全规则仅作用于客户端请求，控制台和服务端 SDK 始终可以访问。因此必须同时保留云函数内的权限、审计、输入校验和事务保护。
