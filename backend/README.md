# 梦食鲜 CloudBase 后端

本目录是梦食鲜从演示版走向真实商城的服务端与后台基础。截至 2026-09-08，测试环境已部署 `api` 与 `maintenance` 云函数，运营后台已发布，200 条商品草稿已审核启用；微信小程序尚未切换到该数据源，也不代表真实支付和履约已经开放。

## 当前实现

- 统一 CloudBase 云函数：后台认证、商品/素材/首页内容、导入草稿、用户地址、购物车、报价、库存预占、订单与履约状态；
- 独立管理后台：`admin-web`，可管理商品、SKU、素材、价格、仓库、库存、配送范围、运费、订单履约与审计；
- 商品导入保留来源与审核层，现有 200 条商品没有被填入假价格或假图片；
- 未登录商品接口绝不返回价格；登录后也必须经过服务端报价才能得到金额；
- 收货手机号按 AES-256-GCM 密文与脱敏值保存，完整号码没有用户端读取接口；测试环境已配置 PII 加密密钥，密钥只存在云函数环境变量和当前 Windows 用户的受保护本机副本中；
- 下单、库存调整均要求幂等控制；库存预占和订单快照在 CloudBase 事务中写入。
